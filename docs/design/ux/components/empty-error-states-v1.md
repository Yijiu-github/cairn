# Empty and Error States V1

> 状态：🟡 Draft
> 最后更新：2026-05-15
> 范围：R1 桌面端关键空状态、错误状态与恢复动作。

---

## 1. 原则

- 空状态不是“暂无数据”，而是告诉用户下一步怎么开始。
- 错误状态必须说明错误层级：编排 / 任务 / 执行 / 产物 / 运行时。
- 能恢复的错误必须给恢复动作；不能恢复的错误必须给诊断路径。
- 涉及本地路径和 secret 时默认脱敏。

## 2. 全局错误层级

| errorLayer    | zh-CN      | 说明                               | 默认动作                        |
| ------------- | ---------- | ---------------------------------- | ------------------------------- |
| orchestration | 编排错误   | run / task 状态推进异常            | Open trace / Retry planning     |
| task          | 任务错误   | task 依赖、输入、验收条件问题      | Add instruction / Retry task    |
| execution     | 执行错误   | agent runtime、tool call、命令失败 | Retry agent run / Open logs     |
| artifact      | 产物错误   | 产物缺失、不可预览、校验失败       | View provenance / Locate file   |
| runtime       | 运行时错误 | Core / Codex / auth / queue 问题   | Diagnostics / Configure runtime |

## 3. 页面空状态

| 页面            | 场景           | 标题                   | 描述                                                            | 主动作       |
| --------------- | -------------- | ---------------------- | --------------------------------------------------------------- | ------------ |
| Home            | 没有 run       | 创建第一个工程协作运行 | 给 Cairn 一个目标、上下文和验收标准，它会沉淀任务、证据和产物。 | 新建运行     |
| Run List        | 筛选无结果     | 没有符合条件的运行     | 调整状态或时间筛选，或创建一个新的运行。                        | 清除筛选     |
| Artifact Detail | 没有 artifact  | 这里还没有产物         | 运行完成或生成证据后，产物会出现在这里。                        | 打开运行列表 |
| Activity        | 没有事件       | 暂无可回放事件         | 创建或打开一个运行后，关键事件会进入活动时间线。                | 新建运行     |
| Task Explorer   | 搜索无结果     | 没找到匹配任务         | 换一个关键词，或从运行详情中查看任务树。                        | 清除搜索     |
| Runtime Status  | 未配置 runtime | 先连接一个运行时       | Cairn 需要本地 Agent runtime 才能执行任务。                     | 配置运行时   |

## 4. 关键错误状态

### 4.1 Core 启动失败

用户看到：

```text
本地 Core 没有正常启动

Cairn 的界面仍可打开，但暂时不能创建或推进运行。
你可以查看日志、重新启动 Core，或复制脱敏状态给维护者。
```

主动作：`重新启动 Core`
次动作：`打开日志`、`复制脱敏状态`

### 4.2 Codex 未登录

用户看到：

```text
Codex CLI 需要登录

Cairn 已找到 Codex CLI，但当前账号未完成认证。
完成登录后再回到这里运行健康检查。
```

主动作：`查看登录指引`
次动作：`重新检测`

### 4.3 Protected action 被拒绝

用户看到：

```text
已拒绝受保护动作

当前 Agent 运行不会执行这次写入。你可以补充说明，让 Agent 选择其他方案，或取消这个运行。
```

主动作：`补充说明`
次动作：`取消运行`、`查看 trace`

### 4.4 Artifact 不可预览

用户看到：

```text
暂不支持预览此产物

Cairn 已记录来源和路径，但当前界面不能直接预览这个文件类型。
```

主动作：`用外部应用打开`
次动作：`在 Finder 中显示`、`查看来源链`

### 4.5 Trace 为空

用户看到：

```text
还没有 trace 事件

这个对象尚未产生可展示事件。如果你刚启动运行，请稍等几秒或打开日志排查。
```

主动作：`刷新`
次动作：`打开日志`

### 4.6 诊断导出包含敏感路径

用户看到：

```text
导出前请确认诊断内容

诊断包默认会脱敏 token，但本地路径、文件名或日志片段仍可能包含个人信息。
```

主动作：`导出脱敏诊断包`
次动作：`查看包含内容`、`取消`

## 5. 恢复动作规范

| 动作               | 要求                                 |
| ------------------ | ------------------------------------ |
| Retry              | 必须显示 attempt 增加后的影响        |
| Rerun              | 必须说明会创建新的 run，不覆盖原 run |
| Restart Core       | 可恢复但影响当前队列，需确认         |
| Cancel Run         | 危险动作，必须二次确认               |
| Export diagnostics | 默认脱敏，导出前展示包含内容         |
| Reveal local file  | 提醒本地路径可能暴露个人信息         |
