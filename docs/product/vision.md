## 1. 一句话愿景

> **让每个开发者都能在自己的机器上，把 Codex / Claude Code / 本地模型等 runtime 组织成可控、可观察、可回看、可复用的工程执行系统。**

## 2. 三年后的样子

我们希望 Cairn 在三年后达到这样的状态：

- 在重度 AI 编程的个人开发者群体中，**被视为可信赖的本地 AI 工程工作台与 runtime 控制面**
- 一台普通 Windows 11 / macOS Apple Silicon 机器**装上就能跑**，无需注册 SaaS、无需配置云依赖
- 团队场景下，可以**自托管到任意 Linux server**，让远程协作与本地体验对齐
- 拥有**可扩展的 runtime adapter 生态**：Codex CLI、Claude Code CLI、本地模型，以及通用 OpenAI-compatible endpoint 都能接入；adapter 是连接能力，不是产品主价值本身或第三方 endpoint 背书
- 用户的数据**默认归用户所有**，本地优先、可迁移、不被锁定
- 关键工程任务（多步代码改动、调研、改+验+总结）**比上一代工具更可控、更可回看**
- Run / Artifact / Trace / Inspector 成为工程过程的证据层，让用户能审查、接管、复用 runtime 的执行结果

## 3. 我们坚信的几件事

### 3.1 桌面端是产品本体，不是壳

AI 协作工具的未来不应该全在浏览器里。文件、终端、本地进程、长任务——这些都是开发者日常的核心场景。桌面端应当被当作一等产品来做。

### 3.2 协作语义必须共享

Web 与桌面、本地与远程，可以分批交付，但**协作语义只能有一套**。两套核心 = 两套 bug + 两倍维护 + 一定的产品分裂。

### 3.3 人类不是观众

多 Agent 不应该把人类排除在外。**观察、暂停、取消、重试、注入、批准**——这些必须是产品的一等动作，不是隐藏菜单。

### 3.4 runtime-amplified，不是复刻 coding agent

Cairn 不训练、不托管，也不把自己做成任何 coding agent 的复刻品。Codex、Claude Code、本地模型或 OpenAI-compatible endpoint 负责生成与执行；Cairn 负责把这些执行组织成 run，提供状态、证据、接管与复用能力。

### 3.5 run-driven，不是 chat-driven

聊天 UI 是输入方式之一，不是产品本质。真正有价值的是 **OrchestrationRun**：可拆分、可观察、可归因、可回看。

### 3.6 本地优先是态度，不是限制

本地优先不是"只能离线用"。它是一种**默认数据归用户**的态度——支持本地、也支持远程，但不强迫用户上云。

## 4. 我们明确不追求的事

- 成为又一个**通用企业 AI 治理平台**
- 做**所有模型 / 所有 provider / 所有入口**的大宽平台
- 做**单一聊天 bot**
- 做**IDE 内补全型 copilot**
- 做**Codex / Claude Code / Cursor / Cline / Aider 的替代品或复刻版**（不做）
- 做**模型托管平台或 coding agent provider**
- 为任何具体第三方转 API / 反代项目做**官方集成、推荐或教学**
- 做**多 Agent 辩论秀**

## 5. 衡量"成功"的方式

| 维度     | 指标候选                                                                      |
| -------- | ----------------------------------------------------------------------------- |
| 用户覆盖 | 日活个人开发者数、自托管实例数                                                |
| 留存     | 30 天 / 90 天活跃留存                                                         |
| 任务价值 | 单次 OrchestrationRun 平均节省时间（用户自报）                                |
| 信任     | 用户主动续用本地数据的比例                                                    |
| 生态     | 第三方 / 社区贡献的 runtime adapter 数；通用 adapter 与第三方专属背书保持边界 |
| 健康     | crash-free 会话比例                                                           |

具体阈值在 [`roadmap.md`](roadmap.md) 中按 Release 钉。
